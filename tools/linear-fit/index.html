计算方法与适用范围

这里使用普通最小二乘法，使各点的 y 方向残差平方和最小。默认拟合 y = ax + b；仅当实验模型要求截距为零时，才选择过原点拟合。工具至少需要 3 组有限数值，单次最多 2,000 组。

带截距模型的 R² 使用中心化总平方和；过原点模型显示非中心 R²，两者不宜直接比较。标准误差由残差估计，未包含仪器误差、x 方向误差或测量权重，也不是扩展不确定度。R² 的分母为零时显示“—”。

查看拟合公式

带截距：a = Σ[(x − x̄)(y − ȳ)] / Σ(x − x̄)²；b = ȳ − ax̄。

过原点：a = Σxy / Σx²；b 固定为 0。

残差方差 s² = SSE / (n − p)，带截距时 p = 2，过原点时 p = 1。斜率标准误差分别为 √[s² / Σ(x − x̄)²] 和 √[s² / Σx²]。

带截距时，截距标准误差为 √[s²(1/n + x̄² / Σ(x − x̄)²)]。截距固定为 0 时不估计其标准误差。

方法参考：NIST：最小二乘模型拟合。实验中的用法可以看我的弦振动与电磁感应报告，或继续阅读同轴光子晶体实验报告。
